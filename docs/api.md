# API 参考

以下接口仅用于文档展示，不提供真实服务。

## 查询文档列表

- 请求方法：GET
- 请求路径：`/api/docs`
- 功能：返回文档条目列表。

### 请求示例

```bash
curl -X GET "https://example.com/api/docs"
```

### 返回示例

```json
{
  "items": [
    {"id": 1, "title": "使用指南"}
  ]
}
```

## 参数说明

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `page` | integer | 否 | 页码，默认 1 |
| `size` | integer | 否 | 每页条数，默认 20，最大 100 |
| `keyword` | string | 否 | 按标题模糊搜索 |

## 状态码约定

| 状态码 | 含义 | 常见原因 |
| --- | --- | --- |
| 200 | 请求成功 | 正常返回数据 |
| 400 | 请求参数错误 | `size` 超过上限 |
| 404 | 资源不存在 | 路径拼写错误 |
| 500 | 服务端异常 | 需要查看服务日志 |

## 说明

本次实践不要求开发真实后端，上面的接口只用于练习 API 文档的排版方式：
如何写清请求方法、路径、参数表格、返回结构，以及在文档里嵌代码块。
真实的接口文档还应补充鉴权方式、错误码明细和变更记录，这里从略。
